# Briefing: Acessos VIP Clientes — WebsiteApp

## Cliente
Acessos VIP Clientes — https://acessosvipclientes.com.br/

## Missão
Transformar o website atual em um **WebsiteApp** — experiência de aplicativo no navegador, tanto no desktop quanto no celular.

## Requisitos de Design (Revolução)

### Navegação Mobile
- **Bottom navigation bar** com ícones (5 itens: Início, Serviços, Planos, Suporte, Conta)
- **Hamburger menu** (sanduíche) no topo para acesso ao menu completo
- Transições suaves entre "telas" (estilo app nativo)

### Navegação Desktop
- Mesma experiência app-style
- Sidebar retrátil OU bottom nav adaptada
- Design limpo, moderno, com cards e sombras suaves

### PWA
- Service worker para funcionar offline
- Manifest.json para instalar como app no celular
- Responsivo 100%

### Paleta
- Cores do cliente (preservar identidade visual existente)
- Modo escuro opcional

## Tecnologia
- Next.js + Tailwind + shadcn/ui
- Componentes app-style (navegação inferior, sheet/drawer)
- Lucide icons para bottom nav

## Prazo
ASAP — primeiro cliente real

## Observações
Revolução completa do site. Não é só um redesign — é uma mudança de paradigma de website para aplicativo.
